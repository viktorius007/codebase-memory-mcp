## 4. Defects not fixed

- **Outside-block link preservation remains incomplete.** Qualified names are restored, but the five Ruff calls, PM field use, Bevy field uses and semantic relationships prevent the requested invariant.
- **Bounded generic alias implementation proof is missing.** `CycleDetector`’s implementation contains bounded parameters and a const parameter. Retaining full alias arguments fixes unconstrained cases, but the existing verifier still returns `trait_receiver_partial`. I did not bypass that refusal to restore a known-right link without proof.
- **Module-level collision suffix consumers remain incomplete.** Restoring legacy `#L` identities does not repair every textual type lookup that previously relied on a collapsed module spelling. The remaining Bevy field losses require further repair.
- **Named block-local macro visibility is unproved.** The supplied-call control passes on base. It cannot demonstrate the named defect or support a repair claim.

Thus the fn-item-alias and block-glob defects have complete repair evidence; block identity has substantial repairs but fails its invariant; macro visibility has no proved repair.
